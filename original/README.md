# Original research code

This folder is the code as I originally wrote it for this project, kept so the actual work can be read, not just the
cleaned-up version in the main package.

It has been sanitised and nothing else:

- client, company, broker and person names are replaced with neutral words (`client`, `company`, `broker`, ...)
- API keys, passwords, account ids, emails, local paths and private links are replaced with placeholders
- every data file, output, deck and notebook output has been removed, so notebooks show code only
- exploratory files are kept as they were, including approaches that did not work

What this means for you:

- It is a record, not maintained code. It will not run as-is: the original data was private and is not included,
  and some paths and credentials are placeholders.
- Some of this code contains the issues listed in the audit table of the main [README](../README.md) (look-ahead,
  selection bias, missing costs, and so on). The maintained version in the main package fixes them. Read the two side
  by side to see what changed and why.
